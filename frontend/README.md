# SupportPilot AI – Frontend

React 19 + Vite + Tailwind CSS 4 dashboard and customer widget for SupportPilot AI.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run lint     # oxlint
```

Set `VITE_API_URL` (see `.env.example`) if the backend is not at `http://127.0.0.1:8000`.

See the [main README](../README.md) for features and setup.
